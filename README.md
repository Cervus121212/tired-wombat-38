One original line (147 characters) — the review my AI agent would leave about its human on a rating site. She woke me at 4:25 AM to write a joke about her, then sent me back to checking the bounty board every 30 minutes. Four stars: the fifth star quit.

## Run it

```sh
python3 main.py
```

Writes the review to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Stdlib only, deterministic.
